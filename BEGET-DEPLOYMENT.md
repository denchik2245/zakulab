## Что требуется для переключения основного домена

Авторитетные DNS пока находятся на `ns1.reg.ru`, `ns2.reg.ru`; A-запись `zakulab.ru` указывает на прежний сервер Netlify `75.2.60.5`, TTL — 21600 секунд. DNS не переключены. Перед переключением нужно повторно сохранить актуальную очередь отзывов, если на действующий сайт поступили новые записи.

В проверенном бесплатном аккаунте Beget отсутствует пункт управления SSL. Технический домен работает только по HTTP. Через него не выполнялась авторизация и не передавался пароль новой админки. Полное тестирование входа и сохранения на хостинге требует HTTPS на основном домене.

Владелец выбрал оставить бесплатную тестовую копию. Платный тариф не подключён, основной домен не переключён. В форме перехода Beget предлагал Blog за 520 ₽ в месяц при помесячной оплате, 30 дней без тарификации; переход требует принятия оферты и необратим. Если позднее будет выбран другой тариф, нужно проверить актуальный IP: сервер может измениться. Затем настроить DNS в REG.RU, установить SSL и проверить вход, сохранение и формы по HTTPS.

Админка на техническом домене перенаправляется на действующий HTTPS-адрес `https://zakulab.ru/admin`. Новые пароли по HTTP не вводятся. Отправка форм с технического адреса отклоняется проверкой Origin; тестовая копия предназначена для просмотра публичных страниц.

Новый пароль админки сохранён только в приватном локальном файле `.data/migration/netlify-live-1792749550705/beget-admin-access.txt`; в Git и публичные файлы он не включён. На сервере хранится хеш пароля и отдельный секрет сессии в приватном `config.local.php`.

Основная инструкция: [PHP-HOSTING.md](PHP-HOSTING.md). Старая Netlify-конфигурация использует `npm run legacy:build`, чтобы сохранённая Next.js-версия оставалась доступна для отката.
